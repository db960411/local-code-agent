# Local Code Agent

A local coding agent powered by Ollama.

It lets you ask questions about your actual codebase using a local LLM.

Currently designed for codebases containing:

- Java
- Spring
- JavaScript
- TypeScript
- C++
- Lua
- XML
- JSON
- YAML
- Game development projects

## Requirements

- Python 3.10+
- Git
- ripgrep
- Ollama
- qwen3:8b or another tool-capable model

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd local-code-agent
